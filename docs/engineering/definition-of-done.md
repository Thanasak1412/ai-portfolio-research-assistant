# Bootstrap Definition of Done

- Product workspace is isolated from the unrelated parent application.
- Frontend, API, and worker build and start.
- PostgreSQL development/test flows, empty goose migration flow, and sqlc generation succeed.
- OpenAPI validation and generated-code drift checks succeed.
- Unit, integration, E2E, and Compose smoke foundations execute deterministically.
- CI implements formatting, lint/static, test, build, contract, migration, generation, vulnerability, and secret gates.
- Structured logs, correlation IDs, liveness/readiness, and graceful API/worker shutdown are verified.
- Documentation describes actual commands and limitations.
- Authentication and all financial/product functionality remain absent.
